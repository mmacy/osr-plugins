# World

Walks the player through Ironsworn's "Your Truths" worldbuilding: 11 categories of setting choices (The Old World, Iron, Religion, Firstborn, Beasts, Horrors, and more) plus region selection. Writes `TRUTHS.md`.

## Invocation

```
/ironsworn-referee:world
```

Typically the first skill called when starting a new campaign, before `character`.

## What it does

- Lists the 11 truth categories.
- For each, presents the three options (pick, roll 1d100, or invent a custom truth).
- Asks the player which region of the Ironlands they're based in.
- Writes the resulting `TRUTHS.md`.
