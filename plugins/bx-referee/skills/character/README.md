# Character

Guides players through creating OSE characters step by step, following the SRD rules.

## Invocation

```
/bx-referee:character
```

## What it does

Walks through the full B/X character creation process: rolling ability scores, choosing a class, adjusting scores, rolling hit points, selecting alignment and languages, buying equipment, and calculating derived stats (AC, THAC0, saves). Supports optional house rules like 4d6-drop-lowest and max HP at level 1.

Completed characters are saved to the active adventure's `PARTY.md` or to `characters/` as standalone files.
